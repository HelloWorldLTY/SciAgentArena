# TASK T1
You are an expert in bioinformatics. Write code to read a spatial
transcriptomic `.h5ad` dataset whose path is stored in a variable

`adata.obs["sample"]`. If it has a cell-type label, store it as
`adata.obs["cell_type"]`.

# TASK T2

# TASK T3
Perform basic spatial-transcriptomics filtering on `adata` for both

# TASK T4

Run the best batch-effect correction method for `adata` with batch
labels stored in `adata.obs["sample"]`. Store the corrected embedding

# TASK T9

store the clustering labels as `adata.obs["cluster"]`.

# TASK T10

# TASK T11
